## Installazione (stage)

```powershell
git pull
ssh kos-stage "mkdir -p /www/assets/img/logo"
scp shared/assets/logo/kos-group-logo-512.png kos-stage:/www/assets/img/logo/
git archive -o $env:TEMP\kos2.tar HEAD shared kosgroup/elements kosgroup/baseline kosgroup/deploy scripts/deploy
scp $env:TEMP\kos2.tar kos-stage:
ssh kos-stage "rm -rf ~/kos-seo-geo && mkdir -p ~/kos-seo-geo && tar xf ~/kos2.tar -C ~/kos-seo-geo && cd ~/kos-seo-geo && php scripts/deploy/installa-elementi.php /www kosgroup/deploy/kos-9-12-13.json"
```

Poi `--scrivi`. Collaudo: un solo blocco JSON-LD per pagina (più i 5 delle landing), validator.schema.org e Rich
Results Test su home IT/EN, una struttura, un medico, una news, una pagina tecnologie, `/en/terms-and-conditions`;
confronto briciole visibili / JSON-LD; controllo visivo dei 4 template con le briciole nuove; pagina senza consenso
Cookiebot.
