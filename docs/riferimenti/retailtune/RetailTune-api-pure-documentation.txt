Stores API - Server to Server API

Get All Store
GET "https://stores-demo.retailtune.com/endpoint/sl/list.json.php"

This endpoint generates a JSON array containing all JSON objects representing the opened stores in Italian. The structure of the JSONs is the following:

    array cta contains an array of objects representing call to actions (campaigns and promotions). It contains:

        string title is the title of the campaign

        string text is the text of the cta

        string start is the start date of the campaign

        string end is the end date of the campaign

        string text_button is the text inside the button

        string link is the link the cta points to

        string img is the image url

        string tab-img is the tablet image url

        string mob-img is the mobile image url

        string eventonload is the information for the onload event

        string eventonclick is the information for the onclick event

        string type is the type of cta (“campaign” or “promotion”)

        string last-modified is the datetime (in ISO8601) of the last change to the JSON.

    array reviews is an array of objects representing reviews of the store. It contains:

        int rating the rating of the store given (1 to 5)

        string createdTime the time the review was created in the format “day.month.year”

        string author the author username of the review

        string comment the comment of the review

    array overlay: the structure is the same as cta but for overlay campaigns.

    array attributes is an array of json objects describing the attributes active for the store.

        string groupDisplayName is the display name of the group the attribute belongs to. It depends on language.

        string enumValue is a comma separated list of values that complement the information regarding the ser-vice, e.g., if the attribute id is “pay_credit_card_types_accepted” then enumValue
        will contain the kind of credit cards accepted. It depends on language.

        string displayName is the display name, the human-readable name of the attribute. It depends on langua-ge.

        string id is the id of the attribute, it does not depend on language.

        String icon is the url of the icon if present. It is the empty string if the url is not present.

    object store the store data, it contains:

        string GASEND is a piece of information to send for analytics. For this endpoint it will always be “”.

        object hours contains the fields “sun”, “mon”, “tue”, “wed”, “thu”, “fri”, “sat” (days of the week), each of which is associated with an object of the form:

             string morningOpen the morning opening hour in the format “hh:mm”. It is be empty (“”) if the store is closed in the morning.

             string morningClose the morning closing hour in the format “hh:mm”. It is be empty (“”) if the store is closed in the morning.

             string eveningOpen the evening opening hour in the format “hh:mm”. It is be empty (“”) if the store is closed in the evening.

             string eveningClose the evening closing hour in the format “hh:mm”. It is be empty (“”) if the store is closed in the evening.

             boolean close whether the store is closed for that day or not

        string address the address of the store

        string address_1 the first address line

        string address_2 the second address line

        string district the district

        string province the province code

        string zipcode the zipcode

        string country_code the country code

        string country the country name

        string city the city of the store

        string title_near the title to display if the store is near the user

        array custom_fields: array of key/value associations

             string key (name)

             string value (value)

             examples

                 key gbp_add_review_link -> google business profile link to add new review

                 key gbp_add_review_qr_code -> link to QR code to add new review on google business profile

                 key open_date_yyyy_mm_dd -> store opening date in google business profile

        string link the url of the store page

        string text_button_near the text of the button if the store is near the user

        string servertime the datetime (in ISO8601) of the response of the server

        string lon the longitude of the store in degrees (as a decimal number)

        object media an object that contains the keys
              string update_date the datetime of the last update of the media in ISO8601

              array media contains objects of the form:

                  string big the url of the big image (with width 1024 px)

                  string mini the url of the small image (480x480 px)

        string eventonload information for the onload event

        string title the title

        string type the type of store

        string text_button the text for the button

        array special contains the special opening/closing hours in the same format as in hours but with the addi-tional field date which contains a string with the date in the format “yyyy-mm-dd”.

        string id the id of the store

        string link_finder link for the product finder (inactive for Gabrielli)

        string phone the phone number associated to the store

        string eventonclick the information for the onclick event

        string name the name of the store

        string fuso the offset for the time zone

        string fax the fax number associated to the store

        string dayserver the day of the week of the server response as a number, with “monday” being “1”, “tues-day” “2”,…

        string lat the latitude of the store in degrees expressed as a decimal number.

        string whatsapp is the phone number used for whatsapp. It is the empty string if it is miss-ing.

    string cta-intro is an introduction sentence for call to actions.

Endpoint details 2 (standard)

Path: /endpoint/sl/list.json.php

Method and Input

Method: POST
Body: {"types":<array<>, "province":, "attributes":<array<>, "city":, "lang":, “modi-fied-since”:} or “”

where:

input.types is an array containing the types of store, corresponding to the field “name” of the jsons returned by list.type.php. Only stores with one of the specified type will be included in the result.
If it is missing or the empty string then no filter is applied regarding to the store type. If it is set to [] the result will always be []. It is case-sensitive.

input.province is the two-letter province code, corresponding to the field “sigla” of the jsons returnd by list.province.php. Only stores in the specified province will be included in the result. If it is
missing or the empty string then no filter is applied regarding the store province. If it is set to an unknown type the result will always be []. It is case-insensitive.

input.attributes is an array containing the id of some attributes/services, corresponding to the field “id” of the jsons re-turned by list.attribute.php. Only stores that have at least one of the specified
attributes/services will be included in the result. If it is missing or the empty string then no filter is applied regarding the store attributes. If it is set to [] the result will always be []. It is case-
sensitive.

input.city is the city of the stores, corresponding to the field “citta” of the jsons returned by list.city.php. Only stores in the specified city will be included in the result. If it is missing or the empty
string then no filter is applied regarding the store city. If it is set to an unknown city then the result will always be []. It is case-insensitive.

input.lang is the two-letter code of a language, case-insensitive, e.g., “IT”, “it”, “en”, “EN”. If it is unspecified or the empty string then the default language will be used. The default language is “it”. If
the language is not supported the result will be [].

input.modified-since is the datetime in ISO8601 of the last change to the json. Only stores that have been modified after (or in) the specified datetime will be included in the result. It corresponds to
the field “last-modified” of the jsons re-turned by this endpoint.

Output: A JSON array containing all JSON objects representing the stores in the required language and that satisfy all the filters.

Path: /endpoint/sl/index.php

Method and Input

Method: POST
Input: A JSON Object of the form


  {
       "user": {
           "latitude": <float>,
           "longitude": <float>,
           "accuracy": <integer>,
           "device": <string>,
           "session": <string>,
           "radius": <integer>
       },
       "types": <array<<string>> ,
       "province": <string>,
       "attributes": <array<<string>>,
       "city": <string>,
       "lang": <string>,
       “modified-since”: <string>,
       “storeid”: <string>
  }
  or “”


where: input.user.latitude is the latitude expressed in degrees.

input.user.longitude is the longitude expressed in degrees.

input.user.accuracy is the accuracy of the position expressed in meters.

input.user.device is the kind of device the user is using, e.g., “desktop”, “mobile”, “tablet”.

input.user.session is the session token.

input.user.radius is the maximum radius from the point (latitude, longitude) expressed in meters. Only the stores that are inside the radius will be included in the result. If no radius is given the
dafult value is 100000 (100km).

input.types is an array containing the types of store, corresponding to the field “name” of the jsons returned by list.type.php. Only stores with one of the specified type will be included in the result.
If it is missing or the empty string then no filter is applied regarding to the store type. If it is set to [] the result will always be []. It is case-sensitive.

input.province is the two-letter province code, corresponding to the field “sigla” of the jsons returnd by list.province.php. Only stores in the specified province will be included in the result. If it is
missing or the empty string then no filter is applied regarding the store province. If it is set to an unknown type the result will always be []. It is case-insensitive.

input.attributes is an array containing the id of some attributes/services, corresponding to the field “id” of the jsons re-turned by list.attribute.php. Only stores that have at least one of the specified
attributes/services will be included in the result. If it is missing or the empty string then no filter is applied regarding the store attributes. It is case-sensitive.

input.city is the city of the stores, corresponding to the field “citta” of the jsons returned by list.city.php. Only stores in the specified city will be included in the result. If it is missing or the empty
string then no filter is applied regarding the store city. If it is set to an unknown city then the result will always be []. It is case-insensitive.

input.lang is the two-letter code of a language, case-insensitive, e.g., “IT”, “it”, “en”, “EN”. If it is unspecified or the empty string then the default language will be used. The default language is “it”. If
the language is not supported the result will be [].

input.modified-since is the datetime in ISO8601 of the last change to the json. Only stores that have been modified after (or in) the specified datetime will be included in the result. It corresponds to
the field “last-modified” of the jsons re-turned by this endpoint.
input.storeid is the id of the store to be retrieved and corresponds to the id field of the returned JSON. If it is specified and is not the empty string and corresponds to a valid store then every other
query will be ignored and the requested store will be returned. If it is specified and is not the empty string and is not a valid store then [] is returned.

Response

Output code: 200 OK
Output: The JSON of the nearest store from (latitude, longitude) that respects every query. If there is no such store then [] is returned. If storeid is specified and corresponds to a valid store id then
that store will be returned regardless of other queries. See the specification of list.json.php for the explanation of the returned json. The json produced by this endpoint and by list.json.php differ in
the fact that for this endpoint the field GASEND is not the empty string but is “CTA_IP” if in-put.accuracy=-1 or “CTA” otherwise and in other minor details.
