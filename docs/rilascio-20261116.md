# Rilascio dello sprint 3 in produzione (eseguito l'8/11 sera)

Eseguito in anticipo l'8/11 sera, prima dell'inizio della verifica di Cerved/ProWeb (9/11): AA 57/57, KOS 150/150 e
63/63. Restano valide la scaletta e lo script per ripetere il rilascio su uno stage riallineato.

Scaletta unica per i due siti, con lo script `scripts/deploy/rilascio-20261116.sh` (ordine dei passi, prova prima di
ogni scrittura, arresto al primo FERMO). Ogni passo scrive il proprio backup e il file di ripristino.

## Prima del rilascio

1. Verifica di Cerved/ProWeb (9-14/11) conclusa: `aaSchema`, `custom.css`, `kosSchema` sono elementi verificati.
2. Risposte di KOS del 9/11 su email e telefoni AA (Abitare il Tempo, San Martino, Casa Serena, San Faustino, Navigli,
   Villa Pineta, Santa Maria in Chienti) in `anniazzurri/dati/schede/correzioni-sito.json`, file delle TV rigenerato
   (`strutture-in-tv.py --fax --correzioni`) e ricaricato sullo stage con `imposta-tv.php`.
3. Validazione dei testi alternativi proposti (`docs/kos-7-aa-9.md`).
4. Prova generale sullo stage: riallineamento dello stage dalla produzione (13-14/11), poi lo stesso script con
   `--scrivi` sullo stage e i collaudi sotto. Lo stage riallineato è nello stato della produzione: la prova è fedele.
5. Snapshot MODX Cloud dei due cloud di produzione il giorno del rilascio.

## Comandi (PowerShell)

```powershell
git -C $R pull
```

```powershell
git -C $R archive -o $env:TEMP\sprint3.tar HEAD anniazzurri kosgroup shared scripts
```

```powershell
scp $env:TEMP\sprint3.tar aa-prod:~/sprint3.tar; scp $env:TEMP\sprint3.tar kos-prod:~/sprint3.tar; Start-Sleep 15
```

Prova (nessuna scrittura; vale il primo passo, i successivi dipendono da quelli prima):

```powershell
ssh aa-prod "rm -rf ~/sprint3 && mkdir -p ~/sprint3 && tar xf ~/sprint3.tar -C ~/sprint3 && cd ~/sprint3 && sh scripts/deploy/rilascio-20261116.sh aa"
```

Rilascio:

```powershell
ssh aa-prod "cd ~/sprint3 && sh scripts/deploy/rilascio-20261116.sh aa --scrivi"
```

```powershell
ssh kos-prod "rm -rf ~/sprint3 && mkdir -p ~/sprint3 && tar xf ~/sprint3.tar -C ~/sprint3 && cd ~/sprint3 && sh scripts/deploy/rilascio-20261116.sh kos --scrivi"
```

Se lo script si ferma: leggere il passo indicato, risolvere, rilanciare lo stesso comando (i passi già scritti
risultano già aggiornati). Per lo stage: stessi comandi con `aa-stage` e `kos-stage`.
